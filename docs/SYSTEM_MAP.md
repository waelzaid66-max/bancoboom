# SYSTEM_MAP — BANCO / B-OOM Production Monorepo

> Phase 4.5 architectural analysis · Source of truth repo: `bancoo` @ `66d2949` · Generated by Claude (analysis only, no code changes).

## 1. Workspace
- **Package manager:** pnpm@11.9.0 (enforced via `scripts/preinstall-enforce-pnpm.mjs`).
- **Layout:** pnpm workspace — `artifacts/*` (deployable apps) + `lib/*` (shared packages). `private: true`.
- **Build:** `pnpm run typecheck && pnpm -r --if-present run build`.
- **Typecheck:** libs first (`tsc --build`) then every artifact's own `typecheck`.

## 3. Shared libraries (`lib/`) — 8 packages
| Lib | Role |
|-----|------|
| **db** | Drizzle ORM schema + client (Postgres). Source of truth for data model |
| **api-spec** | OpenAPI spec (`openapi.yaml`) — the contract |
| **api-zod** | Zod schemas generated/derived from the spec (server validation) |
| **api-client-react** | orval-generated React Query client (consumed by ALL frontends) |
| **search-contract** | Shared search param/facet contract (mobile + web) |
| **taxonomy** | Categories, markets, currencies, property/material types |
| **design-tokens** | Shared design tokens (web surfaces) |
| **integrations-openai-ai-server** | AI assistant server integration |

## 4. Entry points & runtime
- **api-server:** `PORT` + `DATABASE_URL` required to boot. Postgres (needs `pg_trgm`). Object storage for media.
- **banco-mobile (web/prod):** `scripts/build.js` (Metro/Expo static export → `static-build/`) then `server/serve.js` serves it + `/status` health.
- **banco-mobile (native):** Expo/EAS (see `app.config.ts` / `app.json` / `eas.json`).
- **Web apps:** Next.js standalone builds.

## 5. Codegen chain (critical — do not break)
`lib/api-spec/openapi.yaml` → **orval** → `lib/api-client-react` (+ `lib/api-zod`) → consumed by every frontend. Any contract change requires regeneration + typecheck of ALL consumers (mobile + web surfaces).

## 6. Auth / Data / Storage (detected)
- **Auth:** Clerk (`CLERK_SECRET_KEY`, `CLERK_PUBLISHABLE_KEY`, `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY`). Mobile OAuth: **google + apple only** (see PRODUCTION_RISKS — Facebook missing).
- **DB:** Postgres via Drizzle (`lib/db`), extension `pg_trgm` required.
- **Storage:** object storage (`OBJECT_STORAGE_*`, `PRIVATE_OBJECT_DIR`) for media uploads.
- **Payments:** Paymob (`PAYMOB_*`) + `PAYMENT_CONFIG_ENCRYPTION_KEY`.
- **AI:** OpenAI (`OPENAI_*`).
- **Email:** Resend (`RESEND_API_KEY`).
